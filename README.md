# tree-sitter-avenger-typst

The Tree-sitter grammar of the subset of Typst markup that avenger's labels support: chart titles, subtitles, the markup of labels, and the other text that avenger renders with `avenger-typst-label`. Its tree follows `typst-syntax`'s, and the constructs that labels don't support are errors. avenger-sql's grammar injects it into the strings of markup.
